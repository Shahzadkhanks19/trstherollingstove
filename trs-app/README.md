# TRS POS KOT printing

Replace all files while preserving the folder structure.

## Added
- Invoice only print option.
- KOT only option that prints two labelled copies: Kitchen Copy and Customer Copy.
- Combined KOT x2 + Invoice option in one print document and one browser print dialog.
- Combined mode is selected by default.
- Reprint Invoice, Reprint KOT x2, and Reprint All actions after checkout.
- KOT includes order number, date/time, dine-in table or takeaway mode, variants/modifiers, quantities, and total item count.
- KOT intentionally excludes prices and payment details.
